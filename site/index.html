The Shift: Desktop AI vs. Physical AI

Software engineers build for desktop assumptions. Real frontline operators work in environments where typing is impossible.

Dimension Desktop AI (Status Quo) FieldKit Physical AI
User Posture Seated at desk, staring at monitor Standing, walking, repairing, greasy hands
Interaction Loop Reactive: User must type or tap first Proactive: AI detects progress & speaks next step
Sensory Input Static files, screenshots, clipboard Dynamic first-person video, binaural audio, IMU
Network Reality Gigabit unmetered fiber / stable Wi-Fi Jittery cellular, intermittent edge, local-first fallback
Privacy Boundary Everything uploaded to cloud server Ephemeral edge processing, confirm-gated streaming

The Four Pillars of FieldKit

Every compliant FieldKit runtime adheres to four core invariants designed for frontline safety and operator autonomy.

👁️
FOV STREAM · 30 FPS

1. First-Person Sensory Ingest

Ingests real-time video and audio from smart glasses (Ray-Ban Meta, Android wearables), chest cams, and inspection drones with motion-stabilized ROI cropping.

⚡
PROACTIVE DAG ENGINE

2. Proactive Anticipation

Instead of waiting for a wake-word or query, FieldKit tracks state changes against a mission checklist and speaks the next instruction before you have to ask.

🛡️
HARDWARE ENCLAVE AES-256

3. Sovereign Privacy Vault

Zero passive recording. Video feeds remain local to edge memory. Audio streams are isolated to the wearer's voiceprint, and external transmissions require strict confirmation.

🌐
LOCAL-FIRST MESH · SUB-127MS

4. Resilient Local-First Edge Execution

Designed to function when cell towers drop. High-frequency safety checks and step validations execute on-device or via local relay, syncing state seamlessly when uplink restores.

🎯
TSM DETERMINISTIC DAG

Mission-Driven State Machine

Breaks complex tasks down into deterministic atomic checkpoints. If a step is skipped or performed out of order, FieldKit alerts the operator immediately.

Open-Source Python SDK & CLI Runtime

Build custom wearable agents, parse state machines, and simulate raycasting on Linux, Android, and macOS.

⚡ FieldKit CLI & Python 3.9+ Engine
Package: fieldkit-sdk v1.0.0

Run deterministic missions directly from your terminal or integrate the state machine, raycasting evaluator, and voice gate into your own edge application. 

# Install SDK & CLI directly
pip install -e sdk/python/

# Run an interactive physical mission

# Test 3D skeletal hand raycast geometry
fieldkit test-raycast
